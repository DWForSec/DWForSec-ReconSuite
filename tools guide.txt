Buatkan framework Python terminal-based production-ready bernama:

DWForSec-ReconSuite

Konsep:
DWForSec-ReconSuite adalah offensive reconnaissance & attack surface intelligence framework berbasis terminal/CLI untuk security researcher, bug bounty hunter, dan offensive security engineer.

Framework ini harus:
- modular
- asynchronous
- scalable
- production-ready
- clean architecture
- modern CLI UX
- automation-focused
- backend-oriented
- real tool execution
- reporting-focused

Jangan buat web dashboard.
Fokus:
- CLI workflow
- orchestration engine
- shell automation
- parsing engine
- attack surface intelligence
- reporting system

==================================================
MAIN FEATURES
==================================================

Framework harus bisa:
- menjalankan recon pipeline
- menjalankan tools security asli
- parsing output tools
- crawling target
- analyze JavaScript/source code
- detect hidden secrets
- vulnerability scanning
- SSL/TLS scanning
- attack surface mapping
- generate report multi-format
- save results
- support internal/local lab testing

==================================================
REAL TOOL EXECUTION
==================================================

Gunakan:
asyncio.create_subprocess_exec()

JANGAN:
- shell=True
- raw shell injection

Semua subprocess:
- async
- timeout
- streaming stdout/stderr
- sanitized argument list

==================================================
TARGET VALIDATION
==================================================

Karena tools ini digunakan untuk local lab dan internal testing pribadi, jangan blokir localhost atau internal/private IP secara default.

Allowed:
- localhost
- 127.0.0.1
- 0.0.0.0
- 10.x.x.x
- 172.16.x.x - 172.31.x.x
- 192.168.x.x
- internal domain
- public domain
- public IP

Tetap lakukan sanitization untuk mencegah command injection.

Tambahkan optional safety mode:

--public-only

Jika mode ini aktif:
blokir localhost dan internal/private IP.
